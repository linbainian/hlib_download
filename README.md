# hlib_download v2

适配新版 `hlib.cc` 的 Tampermonkey 小说下载器，可下载当前单章或从系列页面批量下载整个系列。

## 功能

- 支持文章页：`https://hlib.cc/n/*`
- 支持系列页：`https://hlib.cc/s/*`
- 自动抓取文章的所有分页
- 从系列页按 `#序号` 批量抓取全部文章
- 系列下载前可选择起始章和结束章，默认下载整个系列
- 可自行设置分页间隔与章节间隔，默认分别至少等待 5 秒和 10 秒
- 实际等待时间会随机增加 0%～35%，降低连续访问触发验证的概率
- 只导出 TXT，使用 UTF-8 BOM 和 Windows 换行，保留段落、空行及正文缩进
- 遇到 Cloudflare 验证时使用同登录态隐藏页面加载，不再依赖会返回 403 的 `GM_xmlhttpRequest`
- 显示下载进度，支持中途取消和失败重试

## 安装

1. 打开 [hlib-download-v2.user.js](./hlib-download-v2.user.js) 的源码。
2. 在 Tampermonkey 中新建脚本，用该文件完整替换编辑器内容并保存。
3. 建议先禁用旧版 `hlib图书馆下载`，避免页面上出现两套按钮。

## 使用

### 单章下载

1. 登录 hlib，并打开任意文章页。
2. 点击右下角的“单章下载”。脚本会下载当前这一章及其全部分页。

### 系列下载

可以在文章页或对应系列页点击“系列下载”。脚本读取目录后会显示范围窗口，默认从第 1 章到最后一章；也可以只下载指定章节范围。

## 下载速度

面板提供两个参数：

- `分页间隔`：同一章相邻分页之间的最短等待时间，默认 5 秒。
- `章节间隔`：相邻两章之间的最短等待时间，默认 10 秒。

脚本会在设定值上随机增加 0%～35% 的缓冲。若仍频繁出现验证，可将分页间隔改为 8～10 秒、章节间隔改为 15～20 秒。

## 注意事项

- 请先登录并完成邮箱/人机验证，否则隐藏页面可能超时。
- 批量下载时请保持当前标签页开启；系列较大时需要等待几分钟。
- 脚本始终串行加载，不会并发请求。
